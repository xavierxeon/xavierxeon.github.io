Detailed Description

QNetworkAccessManager with diagnostics for the license server connection: request/response logging (console and/or files) and additionally trusted CA certificates for test servers. With nothing enabled it behaves exactly like a plain QNetworkAccessManager.

Console logging
Logging category "xx.network", debug level, off by default. Enable with QT_LOGGING_RULES="xx.network.debug=true" or xxNetwork().setEnabled(QtDebugMsg, true). Secrets are always redacted.
File capture
setCaptureDirectory or the environment variable LSP_NETWORK_CAPTURE_DIR. One sub-directory "yyyyMMdd-HHmmss-<pid>" per session, one file "NNNN-<METHOD>-<endpoint>.txt" per exchange (request + response, timestamps, duration). Files are created owner-only (0600). Redacted by default; setCaptureRedacted(false) writes live tokens - local debugging only.
Additional CA certificates (test setup)
addCaCertificates or the environment variable LSP_NETWORK_EXTRA_CA (PEM file, e.g. the self-signed certificate of a local Keycloak). They are added to the CA list of requests of THIS manager only; chain and hostname verification stay active, no SSL errors are ignored. Public-key pinning (RestApi) is unaffected.
Redaction
Headers: Authorization (scheme kept), Cookie, Set-Cookie. JSON / form fields: access_token, refresh_token, id_token, code, client_secret, code_verifier, password.
Limitations
Response bodies are captured with peek() when the reply finishes. Callers that read during readyRead (streaming) leave only the unread remainder in the log. Intended for use from a single thread.
